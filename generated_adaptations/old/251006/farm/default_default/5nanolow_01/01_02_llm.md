Reasoning and adaptation strategy:
- Objective: Allocate drones to protect fields by creating groups "protecting {field.id}" for each field with threat_level > 0, and an "idle" group for drones not assigned to protection.
- Observations:
  - Each field has a required number of drones for full protection: field.drones_for_full_protection.
  - The field center can be computed from its bounding box (left, top, right, bottom).
  - We should prioritize fields by threat level (highest first). The rule says fully protect the highest-threat field with the closest drones, and only if enough drones exist. If there aren’t enough drones to fully protect the current highest-threat field, we skip attempting partial protection for that field (to adhere to the rule that partial protection is not fully effective) and try to allocate to the next fields if possible. In practice, we will:
    - Sort fields by threat_level descending (only fields with threat_level > 0).
    - Maintain a pool of available drones (those not yet assigned to a protecting group in this step).
    - For each field in that order, if available_drones_count >= field.drones_for_full_protection, allocate the closest drones to that field's center to the group "protecting {field.id}" and remove them from the available pool.
    - If not enough drones remain for a field, skip it (to focus on fully protected highest-threat targets) and continue to the next field with the remaining drones (which may still be enough for another field to reach full protection).
  - After processing, any drones not assigned to a protecting group are assigned to the "idle" group.
  - Drones' current states are read-only for assignment; we reassign all drones to either "protecting {field.id}" or "idle" as determined.

Implementation details:
- Compute field centers as ((left+right)/2, (top+bottom)/2).
- Distance metric: Euclidean distance between drone location and field center; choose the closest drones first.
- Use environment.assign_group(component, group_id) to assign each drone to the appropriate group.
- Ensure that every drone ends up in exactly one group (either an appropriate "protecting ..." group or "idle").

from generated_adaptations.base_classes.farm import FarmAdaptation


class SmartFarmAdaptation(FarmAdaptation):
    def __init__(self, **kwargs):

    def assign_drones(self, components, environment, group_ids, step: int):
        """
        Assign drones into:
        - "idle": drones not protecting any field
        - "protecting {field.id}": drones protecting a specific field

        Strategy:
        - Consider fields with threat_level > 0 in descending order of threat.
        - For each field, if there are enough available drones to reach
          field.drones_for_full_protection, assign the closest drones to that field's center.
        - If not enough drones remain for a field, skip to the next field (to try for full protection elsewhere).
        - All remaining drones become idle.
        """
        # Prepare a mapping of field centers and sort fields by threat level
        fields = [f for f in environment.fields if getattr(f, "threat_level", 0) > 0]
        # Compute centers
        field_info = []
        for f in fields:
            left = getattr(f, "left", 0)
            top = getattr(f, "top", 0)
            right = getattr(f, "right", 0)
            bottom = getattr(f, "bottom", 0)
            center_x = (left + right) / 2.0
            center_y = (top + bottom) / 2.0
            needed = getattr(f, "drones_for_full_protection", 0)
            threat = getattr(f, "threat_level", 0)
            field_info.append((f, threat, needed, center_x, center_y))

        # Sort by threat level descending
        field_info.sort(key=lambda t: t[1], reverse=True)

        # Track which drones have been assigned to protecting groups
        assigned = set()

        # Helper to compute distance
        def dist(a, b):
            dx = a.location.x - b[0]
            dy = a.location.y - b[1]
            return dx * dx + dy * dy  # squared distance; enough for ordering

        # We need a pool of drones to choose from: all components
        # Build a list of (drone, index) for consistent ordering
        drones = list(components)
        # We'll maintain a set for quick membership
        remaining_indices = set(range(len(drones)))

        # For each field in priority order, attempt full protection if enough drones remain
        for f, threat, needed, cx, cy in field_info:
            if threat <= 0:
                continue
            if len(remaining_indices) < needed:
                # Not enough to fully protect this field; skip it for now
                continue

            # Choose the 'needed' closest drones to this field center
            # Build a list of (distance, index) for remaining drones
            dist_list = []
            for idx in remaining_indices:
                d = drones[idx]
                dx = d.location.x - cx
                dy = d.location.y - cy
                d2 = dx * dx + dy * dy
                dist_list.append((d2, idx))

            dist_list.sort(key=lambda t: t[0])
            chosen_indices = [idx for (_, idx) in dist_list[:needed]]

            # Assign these drones to the protecting group for this field
            group_name = f"protecting {f.id}"
            for idx in chosen_indices:
                environment.assign_group(drones[idx], group_name)
                assigned.add(idx)

            # Remove from remaining pool
            remaining_indices.difference_update(chosen_indices)

        # Finally, assign all drones not yet assigned to any protecting group to idle
        # Determine all drones that have not been assigned to a protecting group yet
        for idx, drone in enumerate(drones):
            if idx in assigned:
                continue
            environment.assign_group(drone, "idle")
