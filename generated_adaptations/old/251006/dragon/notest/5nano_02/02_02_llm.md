Reasoning and updated adaptation strategy:
- Problem with the previous approach: It tended to spawn farmers aggressively, consuming wheat and farmers without building a timely attacking force. This left the dragon alive longer, causing more casualties to the fields and villagers, and resulted in no wins.
- Key improvements:
  - Spawn Warriors first whenever possible. Early warriors increase total Dragon damage output per turn and accelerate kill potential, reducing the time the dragon can harm villagers in the Cave.
  - Only spawn Farmers after exhausting the possibility to spawn Warriors, and only up to the limit allowed by current wheat. This helps ensure wheat is used efficiently to create an offensive force rather than overproducing farmers who may be killed or spend time farming without contributing to the kill early.
  - Always move all Warriors to the Cave (attack) and keep Farmers in Village to farm or spawn, as required.
  - Use the current wheat available in environment.farm.wheat to determine how many spawns can be attempted this step, ensuring we do not over-commit beyond wheat supply.

This strategy aims to build a small but timely attacking force, balance wheat usage between farming and spawning, and reduce the window for the Dragon to whittle down the population.

Python code (SmartAdaptation):
```py
import abc

from generated_adaptations.base_classes.dragon import DragonHuntAdaptation


class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_in_village(self, components, environment, group_ids, step: int):
        # Separate farmers and warriors currently in the Village
        farmers = [c for c in components if getattr(c, "role", None) == "Farmer"]
        warriors = [c for c in components if getattr(c, "role", None) == "Warrior"]

        # 1) All Warriors go to the Cave to attack
        for w in warriors:
            environment.assign_group(w, "cave")

        # 2) Decide spawns among the Farmers using current wheat
        F = len(farmers)
        W = int(getattr(environment.farm, "wheat", 0))

        # Spawn Warriors first: need 2 farmers and 12 wheat per spawn
        max_warrior_spawns = min(F // 2, W // 12)
        s_fw = 2 * max_warrior_spawns  # number of farmers to assign to "spawn warrior"

        # Remaining farmers and wheat after warrior spawns
        rem_f = F - s_fw
        rem_w = W - 12 * max_warrior_spawns

        # Spawn Farmers next: need 2 farmers and 10 wheat per spawn
        max_farmer_spawns = min(rem_f // 2, rem_w // 10)
        s_ff = 2 * max_farmer_spawns  # number of farmers to assign to "spawn farmer"

        # 3) Assign farmers to their respective groups
        idx = 0
        # First, assign to spawn warrior (2 per spawn)
        for _ in range(s_fw):
            environment.assign_group(farmers[idx], "spawn warrior")
            idx += 1
        # Next, assign to spawn farmer (2 per spawn)
        for _ in range(s_ff):
            environment.assign_group(farmers[idx], "spawn farmer")
            idx += 1
        # Remaining farmers stay in farming
        for j in range(idx, F):
            environment.assign_group(farmers[j], "farm")

        return

    def assign_in_cave(self, components, environment, group_ids, step: int):
        # In the Cave: all Warriors attack; Farmers go back to Village
        for c in components:
            if getattr(c, "role", None) == "Warrior":
                environment.assign_group(c, "attack")
            else:
                environment.assign_group(c, "village")

        return
```
