Reasoning and adaptation strategy:
- Goal: Kill the Dragon as fast as possible. Warriors are best deployed to the Cave to deal damage quickly, while Farmers should stay in the Village to farm and generate wheat to enable spawning more villagers.
- Spawn mechanics: To spawn a new villager, at least two villagers must be assigned to a respective spawn group and enough wheat must be available (10 wheat to spawn a Farmer, 12 wheat to spawn a Warrior). For every two villagers in the spawn group, one new villager of the corresponding type is spawned.
- Strategy outline:
  - In assign_in_village:
    - Move all Warriors to the Cave (group "cave") since they should attack the Dragon.
    - Keep Farmers in the Village: mostly assign them to "farm" to maximize wheat production.
    - If there is enough wheat and at least two Farmers are available, use two Farmers in the "spawn farmer" group to spawn a new Farmer. This is a safe, resource-light way to grow our force and sustain farming.
    - We avoid spawning Warriors in the village for simplicity and to adhere to the rule that Warriors should go to the Cave to attack.
  - In assign_in_cave:
    - All Warriors go to "attack" to actually attack the Dragon.
    - All Farmers go to "village" to return to the Village (continue farming or prepare for future spawns).
- This approach ensures a steady wheat income to enable spawns while prioritizing immediate Dragon damage via Warriors in the Cave.

Python implementation:
```py
from generated_adaptations.base_classes.dragon import DragonHuntAdaptation

class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_in_village(self, components, environment, group_ids, step: int):
        # Separate villagers by role
        farmers = [c for c in components if c.role == "Farmer"]
        warriors = [c for c in components if c.role == "Warrior"]

        # 1) Send all Warriors to the Cave (they will attack from there)
        for w in warriors:
            environment.assign_group(w, "cave")

        # 2) Farmers stay in Village to farm by default
        #    We'll optionally spawn a new Farmer if resources allow.
        #    Determine wheat available for spawning
        wheat = getattr(environment.farm, "wheat", 0)

        # Decide spawn plan: spawn 2 Farmers if we have at least 2 farmers
        # and at least 10 wheat (spawn Farmer cost)
        spawn_farm_count = 0
        if len(farmers) >= 2 and wheat >= 10:
            spawn_farm_count = 2  # two farmers go to spawn farmer group to spawn one new farmer

        # Assign farmers to either "spawn farmer" or "farm"
        spawned = 0
        for f in farmers:
            if spawned < spawn_farm_count:
                environment.assign_group(f, "spawn farmer")
                spawned += 1
            else:
                environment.assign_group(f, "farm")

    def assign_in_cave(self, components, environment, group_ids, step: int):
        # Warriors should attack; Farmers should go to Village
        for c in components:
            if c.role == "Warrior":
                environment.assign_group(c, "attack")
            else:
                environment.assign_group(c, "village")
```
