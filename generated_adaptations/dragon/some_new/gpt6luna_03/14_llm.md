The reports point to two conflicting problems: holding villagers back to farm can prevent a spawn, while spending wheat without reserving meals can cause starvation. This version spawns when the wheat covers both the cost and a meal reserve, but farms when that condition is not met. If there are no Warriors and too few villagers in the Village to form a spawn pair, it sends cave villagers home to rebuild the force. I can’t run the simulator here, so this is a targeted revision rather than a verified fix.
