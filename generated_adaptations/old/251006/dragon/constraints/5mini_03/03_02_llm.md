Reasoning and analysis

The Dragon's area attack hits every villager in the Cave, so the primary way farmers ("the fields") suffer is if farmers end up in the Cave. My previous versions already avoided leaving farmers in the Cave (sending them back to the Village), but we can further reduce field damage (and improve steady wheat production) by:

- Ensuring farmers never go to the Cave (always keep them in Village groups).
- Reserving a larger fraction of farmers to farm each turn so wheat production is steady and farmers are protected.
- Spawning more conservatively so we don't strip too many farmers from farming at once.
- Limiting the number of warriors attacking at any one time (attack rotation) to reduce mass casualties among attackers and therefore reduce the churn that forces more spawning and stress on the farm.

The adaptation below implements these principles while keeping assignments deterministic and ensuring every component is assigned exactly once each step. Farmers are prioritized to "farm"; spawning is allowed only when there are enough spare farmer pairs after reserving the protected fraction. In the Cave, only a small attack team (chosen as the healthiest warriors) attacks; remaining warriors are sent back to the Village to stay safe.

```py
from math import ceil
from generated_adaptations.base_classes.dragon import DragonHuntAdaptation

class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        # rotate attack groups across steps if desired in the future
        self._step_counter = 0
        # how many warriors should attack simultaneously (conservative to protect villagers)
        self.ATTACKERS = 2

    def assign_in_village(self, components, environment, group_ids, step: int):
        """
        Village assignment:
          - All warriors are considered for sending to the cave, but we only send a small
            number per step from the Village (to avoid large cave populations).
            Warriors not sent to the Cave will remain in Village and farm (protect them).
          - Farmers: reserve a large fraction to farm (protect the fields). Only allow
            spawning from the remaining farmers in pairs, and be conservative about spawning:
            spawn warrior pairs only if enough wheat remains after reservation; spawn farmer
            pairs only if ample wheat and spare pairs remain.
          - Always assign every component exactly once.
        """
        def g(name):
            return name if name in group_ids else group_ids[0]

        group_cave = g("cave")
        group_farm = g("farm")
        group_spawn_w = g("spawn warrior")
        group_spawn_f = g("spawn farmer")

        # Deterministic partition by role
        warriors = [c for c in components if getattr(c, "role", "").lower() == "warrior"]
        farmers = [c for c in components if getattr(c, "role", "").lower() == "farmer"]

        # 1) Warriors: send only a small attacking/rotation group from village to cave per step.
        #    Others stay in village (farm) to avoid mass casualties.
        #    We choose to send up to ATTACKERS warriors if available.
        send_warriors = min(len(warriors), self.ATTACKERS)
        for i, w in enumerate(warriors):
            if i < send_warriors:
                environment.assign_group(w, group_cave)
            else:
                # keep spare warriors farming to protect them and help wheat if needed
                environment.assign_group(w, group_farm)

        # 2) Farmers: reserve a large fraction to farm (e.g., 70% rounded up), to protect fields
        n_farmers = len(farmers)
        if n_farmers == 0:
            self._step_counter += 1
            return

        wheat = getattr(environment.farm, "wheat", 0)

        # Reserve fraction for farming: keep at least 70% of farmers farming (rounded up),
        # but always keep at least 1 farmer if any exist.
        reserve_fraction = 0.7
        reserve_to_farm = max(1, min(n_farmers, ceil(n_farmers * reserve_fraction)))

        # Farmers list is deterministic ordering; assign reserved farmers to farm first
        idx = 0
        for _ in range(reserve_to_farm):
            environment.assign_group(farmers[idx], group_farm)
            idx += 1

        # Remaining farmers available for spawning (in pairs)
        remaining = farmers[idx:]
        remaining_count = len(remaining)
        available_pairs = remaining_count // 2

        warrior_spawns = 0
        farmer_spawns = 0
        wheat_left = wheat

        # Conservative spawning policy:
        # - spawn warrior pairs only if at least one pair available and >=12 wheat
        # - spawn farmer pairs only if at least one pair available and >=10 wheat
        # But we ensure we do not use more than half of the non-reserved farmers for spawns here.
        # Try to spawn at most one warrior and at most one farmer this step (to avoid stripping farm).
        if available_pairs >= 1 and wheat_left >= 12:
            warrior_spawns = 1
            wheat_left -= 12
            available_pairs -= 1

        if available_pairs >= 1 and wheat_left >= 10:
            farmer_spawns = 1
            wheat_left -= 10
            available_pairs -= 1

        # Now assign spawn pairs deterministically from remaining farmers
        r_idx = 0
        for _ in range(warrior_spawns):
            if r_idx + 1 < len(remaining):
                environment.assign_group(remaining[r_idx], group_spawn_w); r_idx += 1
                environment.assign_group(remaining[r_idx], group_spawn_w); r_idx += 1
            else:
                break

        for _ in range(farmer_spawns):
            if r_idx + 1 < len(remaining):
                environment.assign_group(remaining[r_idx], group_spawn_f); r_idx += 1
                environment.assign_group(remaining[r_idx], group_spawn_f); r_idx += 1
            else:
                break

        # Any leftover remaining farmers go to farm
        while r_idx < len(remaining):
            environment.assign_group(remaining[r_idx], group_farm)
            r_idx += 1

        self._step_counter += 1

    def assign_in_cave(self, components, environment, group_ids, step: int):
        """
        Cave assignment:
          - Select up to ATTACKERS healthiest warriors to "attack".
          - All farmers found in the cave are immediately sent back to the Village ("village")
            to protect them and the fields.
          - Extra warriors (beyond attackers) are sent back to Village so we don't leave many
            villagers exposed in the Cave.
        """
        def g(name):
            return name if name in group_ids else group_ids[0]

        group_attack = g("attack")
        group_village = g("village")

        # Separate warriors and farmers
        warriors = [c for c in components if getattr(c, "role", "").lower() == "warrior"]
        farmers = [c for c in components if getattr(c, "role", "").lower() == "farmer"]

        # Send all farmers back to village (protect fields)
        for f in farmers:
            environment.assign_group(f, group_village)

        # Sort warriors by HP (desc) and choose attackers
        warriors_sorted = sorted(warriors, key=lambda x: getattr(x, "hp", 0), reverse=True)
        attackers = warriors_sorted[:self.ATTACKERS]
        spares = warriors_sorted[self.ATTACKERS:]

        for a in attackers:
            environment.assign_group(a, group_attack)
        for s in spares:
            # send spare warriors back to village to avoid large cave populations
            environment.assign_group(s, group_village)
