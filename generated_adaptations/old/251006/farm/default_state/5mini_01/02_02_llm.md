Reasoning and strategy

Problems with the prior approach
- It assigned every leftover drone to idle after fully protecting the single top field. That wastes available drones that could reduce damage elsewhere.
- It didn't use the fields' "arriving_drones" information (or preferentially treat drones already moving to the target), so drones that were already en-route could be reassigned unnecessarily, increasing movement time.
- It treated all non-selected drones the same, causing excessive reassignments and movement.

Improved strategy
1. Always fully protect the single field with the highest threat_level (tie-break by nearest drone). Count both currently protecting drones and those already arriving (moving_to_field toward that field) as contributing toward full protection.
2. Prefer drones that are already protecting or moving to the target field. When choosing additional drones, prefer idle drones and then drones that are close (minimize travel time).
3. After the top field is guaranteed full protection (including arriving drones), use any remaining drones to reduce risk elsewhere: assign them to the other fields with threat_level > 0 in descending threat order, filling deficits (drones_for_full_protection - (protecting + arriving)) as much as possible. This increases overall number of protecting drones and improves coverage of high-threat fields.
4. Try to minimize reassignment: do not reassign drones that are already protecting or moving_to the field we want them to protect (unless required elsewhere).
5. Explicitly assign every drone to a group each step (either protecting for a field or idle).

This should raise the average number of protecting drones, reduce needless movement, and improve protection coverage of the most-threatened field.

from math import hypot
from generated_adaptations.base_classes.farm import FarmAdaptation

class SmartFarmAdaptation(FarmAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_drones(self, components, environment, group_ids, step: int):
        """
        Improved strategy:
         - Fully protect the highest-threat field (tie-break by nearest drone), counting both protecting and arriving drones.
         - Prefer drones already protecting or already moving to that field.
         - Use remaining drones to partially/fully protect other threatened fields in descending threat order.
         - Minimize reassignments and prefer nearby drones to reduce moving time.
         - Explicitly assign every drone to a valid group (protecting {field.id} or idle).
        """
        idle_group = "idle"
        if idle_group not in group_ids:
            # Nothing valid to assign to; safe-guard.
            return

        # Helper: get all fields with threat > 0
        fields = [f for f in getattr(environment, "fields", []) if getattr(f, "threat_level", 0) > 0]

        # Precompute drone positions
        drone_positions = {}
        for comp in components:
            loc = getattr(comp, "location", None)
            if loc is None:
                drone_positions[comp] = (0.0, 0.0)
            else:
                drone_positions[comp] = (getattr(loc, "x", 0.0), getattr(loc, "y", 0.0))

        if not fields:
            # No threats: idle all drones
            for comp in components:
                environment.assign_group(comp, idle_group)
            return

        # Field center function
        def center(field):
            return ((field.left + field.right) / 2.0, (field.top + field.bottom) / 2.0)

        # Compute min distance to any drone for tie-break
        field_info = []
        for f in fields:
            cx, cy = center(f)
            min_dist = min(hypot(px - cx, py - cy) for px, py in drone_positions.values()) if drone_positions else float('inf')
            field_info.append((f, f.threat_level, min_dist))

        # Select top field: highest threat, then smallest min_dist
        field_info.sort(key=lambda t: (-t[1], t[2]))
        top_field = field_info[0][0]
        top_group = f"protecting {top_field.id}"
        if top_group not in group_ids:
            # If group invalid, fallback to idling all drones
            for comp in components:
                environment.assign_group(comp, idle_group)
            return

        # Gather counts from field attributes (use getattr defaults)
        required_top = int(getattr(top_field, "drones_for_full_protection", 0))
        protecting_top_attr = int(getattr(top_field, "protecting_drones", 0))
        arriving_top_attr = int(getattr(top_field, "arriving_drones", 0))

        # Also compute protecting and arriving from components to be consistent with component states
        protecting_components_top = [c for c in components if getattr(c, "state", None) == "protecting" and getattr(c, "target_id", None) == top_field.id]
        arriving_components_top = [c for c in components if getattr(c, "state", None) == "moving_to_field" and getattr(c, "target_id", None) == top_field.id]

        # Use the component-derived counts primarily (more reliable for our assignments now)
        protecting_now = len(protecting_components_top)
        arriving_now = len(arriving_components_top)
        already_counted = protecting_now + arriving_now

        # Determine how many extra drones we need to assign to top_field from our pool
        needed_top = max(0, required_top - already_counted)

        # Build a selection score for drones relative to a field
        def drone_score_for_field(comp, field_center, field_id):
            px, py = drone_positions.get(comp, (0.0, 0.0))
            dist = hypot(px - field_center[0], py - field_center[1])
            state = getattr(comp, "state", None)
            target = getattr(comp, "target_id", None)

            # Preference ordering (lower is better):
            # 0: already protecting this field
            # 1: already moving to this field
            # 2: idle
            # 3: moving to other / protecting other (but prefer closer by dist)
            if state == "protecting" and target == field_id:
                base = 0
            elif state == "moving_to_field" and target == field_id:
                base = 1
            elif state == "idle":
                base = 2
            else:
                base = 3
            # Return tuple (base, dist) so sorting naturally prefers state and then closer distance
            return (base, dist)

        # Select drones for top_field:
        top_center = center(top_field)
        # Identify components that are already committed to top_field (we will keep them)
        committed_top = set(protecting_components_top + arriving_components_top)

        # Pool of candidate drones we may reassign (exclude already committed)
        pool = [c for c in components if c not in committed_top]

        # Sort pool by preference for top_field
        pool_sorted = sorted(pool, key=lambda c: drone_score_for_field(c, top_center, top_field.id))

        # Choose needed_top from pool_sorted
        selected_for_top_extra = set(pool_sorted[:needed_top]) if needed_top > 0 else set()

        # Compose final set assigned to top_field: committed + selected extras
        assigned_top = set(committed_top) | selected_for_top_extra

        # Now, with remaining drones, try to allocate to other fields in descending threat order
        remaining_drones = [c for c in components if c not in assigned_top]

        # Prepare other fields sorted by priority (exclude top_field)
        other_fields_info = [fi for fi in field_info if fi[0].id != top_field.id]
        # Sort by threat desc, then min dist asc (already mostly sorted, but ensure)
        other_fields_info.sort(key=lambda t: (-t[1], t[2]))

        # For each other field, compute deficit = required - (protecting + arriving) and try to assign up to deficit
        assignments = {comp: idle_group for comp in components}  # default idle, will override for assigned ones

        # First, assign top_field drones
        for comp in assigned_top:
            assignments[comp] = top_group

        # For each other field, assign drones up to the deficit (preferring drones already protecting/moving to that field and nearby)
        for field_tuple in other_fields_info:
            f = field_tuple[0]
            group_name = f"protecting {f.id}"
            if group_name not in group_ids:
                continue  # cannot assign to this field

            required = int(getattr(f, "drones_for_full_protection", 0))
            # Count current protecting and arriving from components for this field (we won't reassign those unless they are in remaining_drones)
            protecting_comp = [c for c in remaining_drones if getattr(c, "state", None) == "protecting" and getattr(c, "target_id", None) == f.id]
            arriving_comp = [c for c in remaining_drones if getattr(c, "state", None) == "moving_to_field" and getattr(c, "target_id", None) == f.id]
            current_count = len(protecting_comp) + len(arriving_comp)

            deficit = max(0, required - current_count)
            if deficit == 0:
                # Keep current protecting/arriving in place (if in remaining_drones)
                for c in protecting_comp + arriving_comp:
                    assignments[c] = group_name
                    if c in remaining_drones:
                        remaining_drones.remove(c)
                continue

            # Build candidate sort by (preference state relative to this field, distance)
            f_center = center(f)
            # Include protecting/arriving first if present
            candidates = [c for c in remaining_drones]
            candidates.sort(key=lambda c: drone_score_for_field(c, f_center, f.id))

            # Select up to deficit
            selected = candidates[:deficit]
            for c in selected:
                assignments[c] = group_name
                if c in remaining_drones:
                    remaining_drones.remove(c)

            # Also assign any protecting/arriving that were in remaining_drones (so we don't leave them as idle)
            for c in protecting_comp + arriving_comp:
                assignments[c] = group_name
                if c in remaining_drones:
                    remaining_drones.remove(c)

        # Any remaining drones that are still unassigned get assigned to idle
        for c in remaining_drones:
            assignments[c] = idle_group

        # Finally, ensure top_field protecting drones (from earlier committed set) are assigned (in case they were in remaining pool)
        for comp in assigned_top:
            assignments[comp] = top_group

        # Explicitly assign every component according to assignments
        for comp in components:
            group = assignments.get(comp, idle_group)
            # Safety: ensure group is valid
            if group not in group_ids:
                group = idle_group
            environment.assign_group(comp, group)
