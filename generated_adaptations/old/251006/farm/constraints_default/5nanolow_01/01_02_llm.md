Reasoning and adaptation strategy:
- Objective: Assign drones to fields to minimize bird damage. We should always fully protect the field with the highest threat level (threat_level > 0). “Fully protected” means enough drones are allocated to the field to meet its drones_for_full_protection requirement. If that field already has full protection, keep the drones there and allocate none extra.
- Observations:
  - Drones can be in groups: idle or protecting a specific field (group name: "protecting {field.id}").
  - The environment provides fields with threat_level and drones_for_full_protection. We should treat the field with the maximum threat_level as the primary target. If multiple fields tie, we can pick any (we’ll pick the one with the highest threat_level, and among ties, the one with the smallest id for determinism).
  - If there are no fields with threat_level > 0, all drones should be idle.
  - We must ensure that every drone is assigned to exactly one group.
  - We should preserve drones already protecting the chosen field if they help reach full protection; otherwise, reassign as needed to ensure full protection for the top field, and assign any remaining drones to idle or other fields as per rule (we only assign to the top field until it's fully protected; remaining drones go idle).
- Strategy steps:
  1) Identify the field with the highest threat_level > 0. If none, assign all drones to idle.
  2) Determine required_drones = drones_for_full_protection for that field (rounded to int if necessary).
  3) Count how many drones are currently assigned to protecting that field (group "protecting {field.id}"). Keep those in place.
  4) If current_protecting < required_drones, assign additional drones from the pool of drones not already protecting this field to the same group until we reach the required count.
  5) Assign all remaining drones to idle (unless there is a tie-breaker avoidance; but per strategy, only the top field gets protection until full; others go idle).
  6) For completeness, ensure all drones are explicitly assigned to a group via environment.assign_group(component, group_id).

class SmartFarmAdaptation(FarmAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_drones(self, components, environment, group_ids, step: int):
        """
        Assign drones to protect the field with the highest threat level.
        - Idle all drones by default.
        - Find the top threat field (threat_level > 0). If none, assign all to idle.
        - For the top field, ensure it has drones_for_full_protection drones protecting it.
        - Maintain drones already protecting that field if needed to reach full protection.
        - Assign any remaining drones to idle (or reassign to the top field to reach full protection).
        """
        # Prepare names
        protected_groups = {}
        for field in environment.fields:
            if getattr(field, "threat_level", 0) > 0:
                group_name = f"protecting {field.id}"
                protected_groups[field.id] = group_name

        # Determine the top field by threat level
        top_field = None
        top_threat = -1.0
        for field in environment.fields:
            tl = getattr(field, "threat_level", 0.0)
            if tl > top_threat and tl > 0:
                top_threat = tl
                top_field = field

        # If no field needs protection, set everyone to idle
        if top_field is None:
            for comp in components:
                environment.assign_group(comp, "idle")
            return

        top_group_id = f"protecting {top_field.id}"
        # Ensure the top field has a group_id in the provided list
        if top_group_id not in group_ids:
            # If not provided, fall back to 'idle' for safety
            for comp in components:
                environment.assign_group(comp, "idle")
            return

        # Determine required number of drones for full protection
        required_drones = getattr(top_field, "drones_for_full_protection", None)
        if required_drones is None:
            # Fallback to using all drones if not specified
            required_drones = len(components)
        try:
            required_drones = int(required_drones)
        except Exception:
            # If it's not an int-like value, try to cast safely
            try:
                required_drones = int(float(required_drones))
            except Exception:
                required_drones = len(components)

        # Count how many drones are already protecting the top field
        current_protecting = 0
        for comp in components:
            if getattr(comp, "state", None) == "protecting" and getattr(comp, "target_id", None) == top_field.id:
                # Heuristic: if assigned to the same group, it's protecting this field
                if getattr(comp, "location", None) is not None:
                    current_protecting += 1

        # First, assign all drones currently protecting top_field to the correct group (no change)
        # Then assign additional drones if needed
        assigned = set()
        for idx, comp in enumerate(components):
            # If already protecting this field, keep it as is
            if getattr(comp, "state", None) == "protecting" and getattr(comp, "target_id", None) == top_field.id:
                environment.assign_group(comp, top_group_id)
                assigned.add(comp)
        
        # If we still need more drones for full protection, pick unassigned drones and assign
        if current_protecting < required_drones:
            needed = required_drones - current_protecting
            for comp in components:
                if needed <= 0:
                    break
                if comp in assigned:
                    continue
                # Assign this drone to the top protection group
                environment.assign_group(comp, top_group_id)
                assigned.add(comp)
                current_protecting += 1
                needed -= 1

        # All remaining drones become idle
        for comp in components:
            if comp not in assigned:
                environment.assign_group(comp, "idle")
