Reasoning:
- The previous approach limited spawning to farmers and avoided spawning warriors, which reduced the growth of future attacking forces and wheat income. To improve outcomes, we should exploit spawning more aggressively while maintaining the rule that all Warriors should eventually go to the Cave to attack.
- In the village, we can spawn both farmers and warriors by pairing farmers in the spawn groups. Each spawn farmer pair costs 10 wheat and yields a new Farmer; each spawn warrior pair costs 12 wheat and yields a new Warrior. We must ensure every villager is assigned exactly once, so we compute the number of spawn pairs for farmers and warriors from the current population and wheat, then assign exactly one group per villager.
- In the cave, Warriors attack the Dragon, Farmers return to the village.

Updated strategy:
- In assign_in_village:
  - Classify villagers by role.
  - Compute available spawn pairs:
    - farm_spawns = min(number_of_farmers // 2, wheat // 10)
    - remaining_farmers_after_farm_spawns = number_of_farmers - 2 * farm_spawns
    - war_spawns = min(remaining_farmers_after_farm_spawns // 2, (wheat - 10 * farm_spawns) // 12)
  - Assign players in a deterministic order:
    - First 2 * farm_spawns farmers -> "spawn farmer"
    - Next 2 * war_spawns farmers -> "spawn warrior"
    - Remaining farmers -> "farm"
    - All warriors -> "cave"
  - Deduct wheat: 10 * farm_spawns + 12 * war_spawns
- In assign_in_cave:
  - Warriors -> "attack"
  - Farmers -> "village"
  - (Others fallback to "cave")

Code (single block, importing the correct base class):

```py
from __future__ import annotations
import abc

# Import the correct base class from the given module
from generated_adaptations.base_classes.dragon import DragonHuntAdaptation


class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_in_village(self, components, environment, group_ids, step: int):
        """
        Assign villagers in the Village into groups with explicit one-pass assignment:
        - "farm": Farmers farming in village
        - "cave": Farmers going to Cave (via cave group, but we assign to cave directly)
        - "spawn farmer": Pairs of Farmers spawn new Farmers (consume 10 wheat)
        - "spawn warrior": Pairs of Farmers spawn new Warriors (consume 12 wheat)
        All Warriors should go to the Cave (will be attacked later).
        """
        farmers = [c for c in components if getattr(c, "role", None) == "Farmer"]
        warriors = [c for c in components if getattr(c, "role", None) == "Warrior"]

        wheat = getattr(environment.farm, "wheat", 0)

        # Compute possible spawns
        farm_spawns = min(len(farmers) // 2, wheat // 10)
        remaining_farmers = len(farmers) - 2 * farm_spawns
        # Wheat left after farm spawns
        wheat_left = max(0, wheat - 10 * farm_spawns)

        war_spawns = 0
        if remaining_farmers >= 2:
            war_spawns = min(remaining_farmers // 2, wheat_left // 12)
        # Final wheat deduction
        wheat_consumed = 10 * farm_spawns + 12 * war_spawns
        wheat_after = max(0, wheat - wheat_consumed)

        # Assign exactly once per component
        farmer_idx = 0  # to track order among farmers
        for c in components:
            role = getattr(c, "role", None)
            if role == "Warrior":
                environment.assign_group(c, "cave")
            elif role == "Farmer":
                # In order: first farm_spawns pairs -> spawn farmer
                if farmer_idx < 2 * farm_spawns:
                    environment.assign_group(c, "spawn farmer")
                elif farmer_idx < 2 * farm_spawns + 2 * war_spawns:
                    environment.assign_group(c, "spawn warrior")
                else:
                    environment.assign_group(c, "farm")
                farmer_idx += 1
            else:
                # Fallback
                environment.assign_group(c, "farm")

        # Note: The environment's wheat state is external; we reflect consumption by computing wheat_after
        # but we do not modify environment.farm.wheat here because the environment API does not specify a setter.
        # The test framework typically tracks consumption via spawning actions.

    def assign_in_cave(self, components, environment, group_ids, step: int):
        """
        Assign villagers in the Cave into groups:
        - "attack": Warriors attack the Dragon
        - "cave": Stay in the Cave
        - "village": Go to the Village
        """
        for c in components:
            role = getattr(c, "role", None)
            if role == "Warrior":
                environment.assign_group(c, "attack")
            elif role == "Farmer":
                environment.assign_group(c, "village")
            else:
                environment.assign_group(c, "cave")
```
