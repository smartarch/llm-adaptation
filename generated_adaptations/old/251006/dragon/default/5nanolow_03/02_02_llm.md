Reasoning and updated adaptation strategy:
- Goal: Improve win rate by making spawning and army composition more reliable, while ensuring every villager is assigned exactly once per step.
- Key observations:
  - Warriors must always be sent to the Cave and then attack the Dragon.
  - Farmers are the wheat producers; we should spawn new villagers only when we have enough wheat, but we also want to ensure we don’t stall by keeping too many farmers farming without converting some into spawns when wheat allows.
  - Spawning consumes wheat and uses two villagers per spawn (two for the new farmer or two for the new warrior). So we should greedily allocate wheat to spawns in a single pass, first deciding how many spawn farmers we can support, then how many spawn warriors we can support with the remaining farmers and wheat.
  - We must assign each component exactly once in assign_in_village, avoiding any repeated or missing assignments.
- Updated approach:
  - In assign_in_village:
    - Classify villagers by role (Farmers, Warriors).
    - Do not pre-assign; instead, determine s_f and s_w deterministically in one pass:
      - s_f = min(number_of_farmers // 2, wheat // 10)
      - remaining_wheat = wheat - s_f * 10
      - available_for_war_spawns = max(0, number_of_farmers - 2*s_f)
      - s_w = min(available_for_war_spawns // 2, remaining_wheat // 12)
    - Assign first 2*s_f farmers to "spawn farmer".
    - Assign next 2*s_w farmers to "spawn warrior".
    - All remaining farmers go to "farm".
    - All warriors go to "cave" (to attack in the cave step).
  - In assign_in_cave:
    - Warriors stay in "attack" to face the Dragon.
    - Farmers go to "village" to farm/spawn as needed.
- This keeps a single, consistent assignment per component and improves resource usage planning.

import abc
from typing import List
from generated_adaptations.base_classes.dragon import DragonHuntAdaptation

class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_in_village(self, components, environment, group_ids, step: int):
        """
        Divide Villagers in the Village into:
        - "farm": stay in Village and farm
        - "cave": go to Cave (to be attacked later)
        - "spawn farmer": for every two villagers assigned here and 10 wheat, spawn a Farmer
        - "spawn warrior": for every two villagers assigned here and 12 wheat, spawn a Warrior
        """
        # Classify villagers by current role
        farmers = [c for c in components if getattr(c, "role", None) == "Farmer"]
        warriors = [c for c in components if getattr(c, "role", None) == "Warrior"]

        # Current wheat available from farm resource
        wheat = 0
        if hasattr(environment, "farm") and hasattr(environment.farm, "wheat"):
            wheat = environment.farm.wheat

        # Determine spawns using the pool of farmers only (no repeated assignments)
        max_possible_farm_spawns = wheat // 10
        s_f = min(len(farmers) // 2, max_possible_farm_spawns)

        # After allocating s_f spawns for farmers, reduce wheat
        remaining_wheat = wheat - s_f * 10

        # Determine spawns for warriors using remaining wheat and remaining farmers
        max_war_spawns_now = remaining_wheat // 12
        available_for_war_spawns = max(0, len(farmers) - 2 * s_f)
        s_w = min(available_for_war_spawns // 2, max_war_spawns_now)

        # Finalize assignments ensuring exactly one assignment per component
        # 1) Assign farmers to spawn groups or farm in a single pass
        if s_f > 0:
            for c in farmers[:2 * s_f]:
                environment.assign_group(c, "spawn farmer")
        if s_w > 0:
            for c in farmers[2 * s_f : 2 * s_f + 2 * s_w]:
                environment.assign_group(c, "spawn warrior")
        # Remaining farmers go to farm
        for c in farmers[2 * s_f + 2 * s_w:]:
            environment.assign_group(c, "farm")

        # 2) All warriors go to cave
        for w in warriors:
            environment.assign_group(w, "cave")

    def assign_in_cave(self, components, environment, group_ids, step: int):
        """
        Divide Villagers in the Cave into:
        - "attack": Attack the Dragon
        - "cave": Stay in the Cave
        - "village": Go to the Village
        """
        # Warriors should attack; Farmers should go to village
        for c in components:
            if getattr(c, "role", None) == "Warrior":
                environment.assign_group(c, "attack")
            else:
                environment.assign_group(c, "village")
