Reasoning and adaptation strategy:
- Task overview: We control villagers to defeat a Dragon as fast as possible. Warriors are best used for direct attacks in the Cave; Farmers generate Wheat in the Village and can spawn new villagers when enough Wheat and the right grouping are met. Spawn mechanics require at least two villagers in a spawn group and a Wheat threshold (10 for spawning a Farmer, 12 for spawning a Warrior).
- Key constraints:
  - All Warriors should go to the Cave and attack the Dragon.
  - All Farmers should stay in the Village, where they farm or help spawn new villagers.
  - We must assign every component to exactly one group per method call. If a component should continue with the same action as before, it must be explicitly reassigned to that group.
- Strategy:
  - Village assignment:
    - Move all Warriors to the Cave (group "cave").
    - Keep Farmers in the Village (group "farm") by default.
    - Use the "spawn farmer" group to trigger spawning of new Farmers when Wheat is available. The number of farmers placed in the "spawn farmer" group should be limited by both the number of Farmers present and the Wheat available in the Farm: max_spawn_farmers = min(number_of_farmers // 2, Wheat // 10). We assign 2*max_spawn_farmers Farmers to the "spawn farmer" group and the rest stay in "farm".
    - We do not actively use the "spawn warrior" group to avoid complicating the dynamic; it can be extended in a future refinement if needed.
  - Cave assignment:
    - All Warriors go to "attack" to fight the Dragon.
    - All Farmers go to "village" to return and continue farming/spawning.
- This approach ensures immediate offensive force from Warriors while sustaining wheat production and potential spawning of new Farmers, keeping the overall headcount adaptable to Wheat availability. Spawns are driven by Wheat, so if Wheat is low, no spawns occur; if Wheat is plentiful, we can gradually grow the village.

from generated_adaptations.base_classes.dragon import DragonHuntAdaptation

class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_in_village(self, components, environment, group_ids, step: int):
        """
        Assign villagers in the Village into:
        - "farm": stay in Village and farm
        - "cave": go to the Cave (for Warriors only, by policy)
        - "spawn farmer": for every two villagers assigned here and 10 wheat, a new Farmer is spawned
        - "spawn warrior": reserved for spawning Warriors (not actively used in this strategy)
        Strategy:
        - Warriors -> "cave"
        - Farmers -> default "farm"
        - Move a subset of Farmers into "spawn farmer" based on available Wheat
        """
        # Collect indices for farmers to decide spawning
        farmers_indices = [i for i, c in enumerate(components) if getattr(c, 'role', None) == "Farmer"]
        n_farmers = len(farmers_indices)

        # Wheat available for spawning farmers
        wheat = getattr(getattr(environment, 'farm', None), 'wheat', 0)

        # How many farmers can we spawn this turn? Each spawn needs 2 farmers and 10 wheat
        max_spawn_farmers = min(n_farmers // 2, wheat // 10)
        # We will assign 2*max_spawn_farmers farmers to the "spawn farmer" group
        spawn_count = 2 * max_spawn_farmers
        spawn_indices = set(farmers_indices[:spawn_count])

        for idx, comp in enumerate(components):
            role = getattr(comp, 'role', None)
            if role == "Warrior":
                environment.assign_group(comp, "cave")
            elif role == "Farmer":
                if idx in spawn_indices:
                    environment.assign_group(comp, "spawn farmer")
                else:
                    environment.assign_group(comp, "farm")
            else:
                # Fallback: keep in farm if unknown role
                environment.assign_group(comp, "farm")

    def assign_in_cave(self, components, environment, group_ids, step: int):
        """
        Assign villagers in the Cave into:
        - "attack": Warriors attack the Dragon
        - "cave": Stay in the Cave
        - "village": Farmers go back to the Village
        Policy:
        - All Warriors go to "attack"
        - All Farmers go to "village"
        """
        for comp in components:
            role = getattr(comp, 'role', None)
            if role == "Warrior":
                environment.assign_group(comp, "attack")
            elif role == "Farmer":
                environment.assign_group(comp, "village")
            else:
                environment.assign_group(comp, "village")
