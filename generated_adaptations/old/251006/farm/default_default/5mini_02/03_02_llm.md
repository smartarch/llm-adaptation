"""
SmartFarmAdaptation (Improved redistribution strategy)

Reasoning and strategy (step-by-step):

Problem recap:
- We must always fully protect the single field with the highest threat_level using the closest drones,
  and explicitly assign every drone to a group each step.
- Previous strategies favored idle and surplus drones, but the most-threatened field remained under-covered (~0.6).
  This suggests we were too conservative about pulling drones away from other protected fields.

Goal for improvement:
- Ensure the highest-threat field gets full protection more reliably and faster, by more intelligently
  selecting which drones to reassign.
- Minimize collateral damage caused by removing drones from other fields by choosing drones whose reassignment
  has the lowest marginal cost in terms of potential increase of damage elsewhere.
- Still favor drones that can arrive quickly.

Key ideas in this improved strategy:
1. Compute for every field (including the highest) the number of drones currently assigned to it.
2. For each candidate drone (not already committed to the highest field), compute:
   - arrival_time = distance_to_highest_center / drone_speed
   - marginal_cost_of_removal: an estimate of how harmful it is to remove this drone from its current target.
     We compute this as: threat_level_of_current_field * max(0, drones_needed_if_removed)
     where drones_needed_if_removed = max(0, drones_for_full_protection - (assigned_count - 1)).
     This captures that removing a drone from a field that already has surplus has near-zero cost,
     while removing the last drone from a field with a high threat_level has high cost.
3. Combine arrival_time and marginal_cost into a single score:
   score = w_time * arrival_time + w_cost * marginal_cost
   Lower score = better candidate to move.
   We choose weights so that marginal_cost is prioritized (to avoid creating high-cost deficits),
   but arrival_time still matters to reduce time_to_protect.
4. Select the top candidates by score to reach the required number for full protection.
   If not enough candidates, select as many as possible.
5. Assign:
   - drones already committed to highest and selected candidates -> protecting highest field.
   - other drones that are currently targeting a threatened field -> keep protecting that field.
   - remaining drones -> idle.

Parameters chosen:
- DRONE_SPEED = 2.0 (given)
- w_time = 1.0
- w_cost = 8.0 (empirically chosen to strongly prefer low-cost removals but still consider arrival time)

This strategy should be more aggressive about pulling low-impact drones (idle, surplus, or from low-threat fields)
while avoiding pulling high-impact drones (those whose removal would create a deficit on a high-threat field).
It also favors drones that can arrive quickly to the highest field.
"""

from typing import List, Dict, Tuple
from math import sqrt
from generated_adaptations.base_classes.farm import FarmAdaptation


class SmartFarmAdaptation(FarmAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_drones(self, components: List[object], environment: object, group_ids: List[str], step: int):
        # Parameters
        DRONE_SPEED = 2.0
        w_time = 1.0
        w_cost = 8.0

        # Helpers
        def field_center(f):
            return ((f.left + f.right) / 2.0, (f.top + f.bottom) / 2.0)

        # Build field lookup by id
        field_by_id: Dict[str, object] = {}
        for f in environment.fields:
            field_by_id[f.id] = f

        # Threatened fields (threat_level > 0) and mapping to protecting group names if available
        threatened_fields = [f for f in environment.fields if getattr(f, "threat_level", 0) > 0]
        protecting_group_for_field: Dict[str, str] = {}
        for f in threatened_fields:
            gname = f"protecting {f.id}"
            if gname in group_ids:
                protecting_group_for_field[f.id] = gname

        # If no protecting groups or threatened fields, idle all drones
        if not protecting_group_for_field:
            idle_group = "idle" if "idle" in group_ids else (group_ids[0] if group_ids else "idle")
            for c in components:
                environment.assign_group(c, idle_group)
            return

        # Select the single highest-threat field (tiebreak by id)
        def fld_key(f):
            return (f.threat_level, f.id)
        highest_field = max(threatened_fields, key=fld_key)
        highest_group = protecting_group_for_field.get(highest_field.id, None)
        hf_cx, hf_cy = field_center(highest_field)
        required = int(getattr(highest_field, "drones_for_full_protection", 0))

        # Build mapping of current assignments: target_id -> list of drones
        assigned_by_field: Dict[str, List[object]] = {}
        idle_drones: List[object] = []
        for c in components:
            tgt = getattr(c, "target_id", None)
            if tgt is None:
                idle_drones.append(c)
            else:
                assigned_by_field.setdefault(tgt, []).append(c)

        # Drones already committed to highest field (target_id == highest_field.id)
        committed = assigned_by_field.get(highest_field.id, [])
        committed_ids = set(id(d) for d in committed)
        current_committed = len(committed)
        needed_remaining = max(0, required - current_committed)

        # If no additional drones required, maintain current assignments (but ensure explicit assignment)
        if needed_remaining <= 0:
            idle_group = "idle" if "idle" in group_ids else (group_ids[0] if group_ids else "idle")
            for c in components:
                cid = id(c)
                if cid in committed_ids and highest_group is not None:
                    environment.assign_group(c, highest_group)
                else:
                    t = getattr(c, "target_id", None)
                    if t in protecting_group_for_field:
                        environment.assign_group(c, protecting_group_for_field[t])
                    else:
                        environment.assign_group(c, idle_group)
            return

        # Precompute assigned counts for all fields (including non-threat) for marginal-cost calc
        assigned_count: Dict[str, int] = {}
        for tgt, lst in assigned_by_field.items():
            assigned_count[tgt] = len(lst)

        # Build candidate list of drones that can be re-assigned to the highest field
        # Exclude those already committed
        candidates: List[Tuple[float, float, object]] = []  # (score, arrival_time, comp)

        for c in components:
            if id(c) in committed_ids:
                continue  # already counted
            # Compute arrival time to highest field center
            try:
                dx = float(c.location.x) - hf_cx
                dy = float(c.location.y) - hf_cy
                dist = sqrt(dx * dx + dy * dy)
            except Exception:
                dist = float("inf")
            arrival_time = dist / DRONE_SPEED

            # Compute marginal cost of removing this drone from its current assignment
            tgt = getattr(c, "target_id", None)
            if tgt is None:
                # idle drones: cost 0
                marginal_cost = 0.0
            else:
                # Find field info (if any)
                f = field_by_id.get(tgt, None)
                # If not a known field, treat as low cost (0)
                if f is None:
                    marginal_cost = 0.0
                else:
                    f_threat = getattr(f, "threat_level", 0.0)
                    f_required = int(getattr(f, "drones_for_full_protection", 0))
                    f_assigned = assigned_count.get(tgt, 0)
                    # If removing this drone leaves assigned >= required -> no immediate deficit (cost 0)
                    if f_assigned - 1 >= f_required:
                        marginal_cost = 0.0
                    else:
                        # If removal creates deficit, cost proportional to threat and deficit size
                        deficit_after = max(0, f_required - (f_assigned - 1))
                        # scale by threat; using deficit_after gives larger cost if removal causes larger shortfall
                        marginal_cost = f_threat * deficit_after

            # Compute score (lower is better)
            score = w_time * arrival_time + w_cost * marginal_cost
            candidates.append((score, arrival_time, c))

        # Sort candidates by score, then arrival_time, then id for determinism
        candidates.sort(key=lambda x: (x[0], x[1], id(x[2])))

        # Select top-needed_remaining candidates
        selected_for_highest_ids = set()
        for i in range(min(needed_remaining, len(candidates))):
            _, _, comp = candidates[i]
            selected_for_highest_ids.add(id(comp))

        # If we still don't have enough (unlikely), fallback: pick nearest remaining drones regardless of cost
        if len(selected_for_highest_ids) < needed_remaining:
            remaining = [c for c in components if id(c) not in committed_ids and id(c) not in selected_for_highest_ids]
            rem_list = []
            for c in remaining:
                try:
                    dx = float(c.location.x) - hf_cx
                    dy = float(c.location.y) - hf_cy
                    dist = sqrt(dx * dx + dy * dy)
                except Exception:
                    dist = float("inf")
                arrival = dist / DRONE_SPEED
                rem_list.append((arrival, c))
            rem_list.sort(key=lambda x: (x[0], id(x[1])))
            need_more = needed_remaining - len(selected_for_highest_ids)
            for i in range(min(need_more, len(rem_list))):
                _, comp = rem_list[i]
                selected_for_highest_ids.add(id(comp))

        # Final assignment for every drone
        idle_group = "idle" if "idle" in group_ids else (group_ids[0] if group_ids else "idle")
        for c in components:
            cid = id(c)
            if cid in committed_ids and highest_group is not None:
                environment.assign_group(c, highest_group)
            elif cid in selected_for_highest_ids and highest_group is not None:
                environment.assign_group(c, highest_group)
            else:
                # Keep protecting current threatened target if possible
                t = getattr(c, "target_id", None)
                if t in protecting_group_for_field:
                    environment.assign_group(c, protecting_group_for_field[t])
                else:
                    environment.assign_group(c, idle_group)
