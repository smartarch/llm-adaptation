Reasoning and updated adaptation strategy:
- Goal and constraints recap:
  - All Warriors must go to the Cave and attack the Dragon.
  - Farmers stay in the Village and are used for farming or spawning new villagers.
  - Spawns require 2 villagers in a spawn group and a wheat cost (10 for Farmer, 12 for Warrior).
  - The Dragon can retaliate, and you want to minimize damage to villagers in the Cave (i.e., minimize the time and number of villagers in the Cave while keeping the Dragon under rapid pressure).

- Observations from the prior run:
  - A purely greedy per-step spawn can generate large waves of Farmers, which increases wheat demand and can prolong exposure risk in the Cave.
  - Early and sustained Warrior presence in the Cave accelerates dragon kill, reducing the number of Dragon attacks on Cave villagers.
  - There is value in a staged strategy that keeps a farming wheat pipeline while rapidly building a Warrior force once enough wheat is accumulated.

- New adaptation strategy (stage-guided, dynamic spawns):
  - Stage 0 (steps 0-4): Focus on farming to build a stable wheat reserve. All Warriors are sent to the Cave immediately, but no spawning is attempted yet.
  - Stage 1 (steps >= 5): Use available wheat and Farmers to spawn as many Warriors as possible to strengthen the early assault, while also spawning Farmers as needed to sustain future wheat production. Specifically:
    - First compute how many Warrior-spawns we can do: max_war_spawns = min(num_farmers // 2, wheat // 12).
    - Then compute remaining Farmers and remaining Wheat to determine Farmer-spawns: max_farm_spawns = min( (num_farmers - 2*max_war_spawns) // 2, (wheat - 12*max_war_spawns) // 10 ).
    - Assign 2*max_war_spawns Farmers to "spawn warrior" and 2*max_farm_spawns Farmers to "spawn farmer"; the rest of Farmers go to "farm".
  - Cave handling stays consistent: all Warriors attack; Farmers in Cave are moved back to Village.
  - This staged approach aims to keep fields safe by boosting dragon kill speed early, reducing the window during which the Dragon can attack Cave villagers, while preserving a wheat pipeline via farming and controlled spawning.

- Implementation notes:
  - The code robustly handles missing environment.farm.wheat by defaulting to 0.
  - The approach adheres to the required interface and uses environment.assign_group(component, group_id) to assign groups.
  - The logic ensures All Warriors go to the Cave in assign_in_village, and Farmers who are already in the Cave are moved back in assign_in_cave.

from generated_adaptations.base_classes.dragon import DragonHuntAdaptation


class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_in_village(self, components, environment, group_ids, step: int):
        # Separate villagers by role
        farmers = [c for c in components if getattr(c, "role", "").lower() == "farmer"]
        warriors = [c for c in components if getattr(c, "role", "").lower() == "warrior"]

        # 1) All Warriors should go to the Cave
        for w in warriors:
            environment.assign_group(w, "cave")

        num_farmers = len(farmers)
        if num_farmers == 0:
            return

        # Wheat available for spawning (robust to missing farm information)
        farm = getattr(environment, "farm", None)
        wheat = getattr(farm, "wheat", 0) if farm is not None else 0

        # Stage-based spawning strategy
        if step < 5:
            # Stage 0: focus on farming; assign all farmers to farming
            for f in farmers:
                environment.assign_group(f, "farm")
            return

        # Stage 1+: aggressive but controlled spawns to boost early dragon damage
        # Compute maximum warrior spawns (need 2 farmers and 12 wheat per Warrior)
        max_war_spawns = min(num_farmers // 2, wheat // 12)

        # Remaining farmers and wheat after Warrior spawns
        remaining_farmers = num_farmers - (2 * max_war_spawns)
        wheat_after_war_spawns = wheat - (12 * max_war_spawns)

        # Compute maximum farmer spawns with the remaining resources
        max_farm_spawns = min(remaining_farmers // 2, wheat_after_war_spawns // 10)

        # Assign groups accordingly
        idx = 0
        # 2 * max_war_spawns farmers -> spawn warrior
        for _ in range(max_war_spawns * 2):
            if idx < num_farmers:
                environment.assign_group(farmers[idx], "spawn warrior")
                idx += 1

        # 2 * max_farm_spawns farmers -> spawn farmer
        for _ in range(max_farm_spawns * 2):
            if idx < num_farmers:
                environment.assign_group(farmers[idx], "spawn farmer")
                idx += 1

        # Remaining farmers -> farming
        while idx < num_farmers:
            environment.assign_group(farmers[idx], "farm")
            idx += 1

    def assign_in_cave(self, components, environment, group_ids, step: int):
        # In the Cave, send Warriors to attack and move Farmers back to Village
        warriors = [c for c in components if getattr(c, "role", "").lower() == "warrior"]
        farmers = [c for c in components if getattr(c, "role", "").lower() == "farmer"]

        # Warriors attack
        for w in warriors:
            environment.assign_group(w, "attack")

        # Farmers should go back to Village
        for f in farmers:
            environment.assign_group(f, "village")

        # If there are any other roles, default them to cave (safety)
        for c in components:
            r = getattr(c, "role", "").lower()
            if r not in ("warrior", "farmer"):
                environment.assign_group(c, "cave")
