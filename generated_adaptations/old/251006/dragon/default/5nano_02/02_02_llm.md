Reasoning and updated strategy

What went wrong
- The previous strategy kept all Warriors in the Cave and focused on farming with Farmers. However, the spawning logic was not consistently leveraged to grow the population and wheat quickly enough, and the distribution did not adapt to the available wheat. Dragons can punish large cave populations, and with only a few remaining Farmers, wheat production can stall, slowing spawns and letting the Dragon survive longer.

Improved strategy
- In the Village:
  - Move all Warriors to the Cave (as required).
  - Use a dynamic, wheat-aware spawning plan for Farmers and Warriors to accelerate growth without starving farming capacity.
  - Specifically, compute how many new Farmers and new Warriors can be spawned this turn given:
    - The number of Farmers available in the Village (F).
    - The current wheat in the Farm (W).
    - Spawning costs: 10 wheat for a new Farmer (needs 2 villagers in the spawn farmer group per spawned Farmer) and 12 wheat for a new Warrior (needs 2 villagers in the spawn warrior group per spawned Warrior).
  - Spawn as many as possible this turn:
    - First, determine max possible Farmer spawns: min(F // 2, W // 10).
    - Then, with the remaining Wheat, determine Warrior spawns: min((F - 2*spawned_farmers) // 2, (W - 10*spawned_farmers) // 12).
  - Assign the corresponding villagers to "spawn farmer" and "spawn warrior" groups (two villagers per spawn). The rest stay in "farm" to continue producing wheat.
  - This approach ensures a steady growth of both population and wheat, enabling faster subsequent spawns and stronger long-term play, while still ensuring Farmers remain in the Village to farm.
- In the Cave:
  - All Warriors stay in the Cave and attack the Dragon (as required).
  - Farmers in the Cave (if any due to edge cases) are moved to the Village in the next cycle, so the Cave occupancy remains primarily Warriors.
- This adaptive spawning makes better use of wheat and reduces the risk of stalling, aiming to kill the Dragon within the 30-step limit.

from generated_adaptations.base_classes.dragon import DragonHuntAdaptation

class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_in_village(self, components, environment, group_ids, step: int):
        """
        Divide Villagers in the Village into:
        - farm: stay in Village and farm
        - cave: go to the Cave
        - spawn farmer: for every two villagers assigned to this group and 10 wheat, a new Farmer is spawned
        - spawn warrior: for every two villagers assigned to this group and 12 wheat, a new Warrior is spawned
        Strategy:
        - Move all Warriors to the Cave (attack group).
        - Among Farmers in the Village, spawn as many new Farmers and Warriors as allowed by the available wheat.
        - The rest of Farmers stay to farm.
        """
        # Gather villagers by role
        farmers = [c for c in components if c.role == "Farmer"]
        warriors = [c for c in components if c.role == "Warrior"]

        # 1) Move all Warriors to the Cave (attack group)
        for w in warriors:
            environment.assign_group(w, "cave")

        # 2) Determine how many spawns we can perform this turn using current wheat
        F = len(farmers)
        wheat = getattr(environment.farm, "wheat", 0)

        # Compute spawn farmer count (2 farmers per spawn, costs 10 wheat per spawn)
        spawn_f_count = 0
        if F >= 2 and wheat >= 10:
            spawn_f_count = min(F // 2, wheat // 10)

        # Remaining farmers after allocating for spawn farmers
        remaining_after_f = F - (2 * spawn_f_count)

        # Compute spawn warrior count (2 villagers per spawn, costs 12 wheat per spawn)
        spawn_w_count = 0
        if remaining_after_f >= 2 and wheat - (spawn_f_count * 10) >= 12:
            spawn_w_count = min(remaining_after_f // 2, (wheat - (spawn_f_count * 10)) // 12)

        # 3) Assign groups
        idx = 0

        # Assign to spawn farmer group
        for _ in range(2 * spawn_f_count):
            environment.assign_group(farmers[idx], "spawn farmer")
            idx += 1

        # Assign to spawn warrior group
        for _ in range(2 * spawn_w_count):
            environment.assign_group(farmers[idx], "spawn warrior")
            idx += 1

        # Remaining farmers go to farming
        for j in range(idx, F):
            environment.assign_group(farmers[j], "farm")

    def assign_in_cave(self, components, environment, group_ids, step: int):
        """
        Divide Villagers in the Cave into:
        - attack: Attack the Dragon
        - cave: Stay in the Cave
        - village: Go to the Village

        Strategy: All Warriors should attack; Farmers should go to the Village.
        """
        for c in components:
            if c.role == "Warrior":
                environment.assign_group(c, "attack")
            else:
                environment.assign_group(c, "village")
