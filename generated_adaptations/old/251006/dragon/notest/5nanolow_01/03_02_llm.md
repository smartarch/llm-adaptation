Reasoning and strategy:
- The goal is to minimize field damage while still killing the Dragon efficiently. Warriors effectively increase DPS, but spawning requires wheat and pairs of farmers. The existing results show that spawning both Warriors and Farmers is beneficial, and keeping Farmers in the Village reduces risk to fields.
- A robust approach is to:
  - In the Village: allocate farmers to three tasks in this order
    1) Spawn as many Warriors as possible, given wheat and available farmers (needs 2 farmers and 12 wheat per Warrior spawned).
    2) Then spawn as many Farmers as possible with the remaining resources (needs 2 farmers and 10 wheat per Farmer spawned).
    3) The rest continue farming.
  - All Warriors should be sent to the Cave to attack the Dragon; Farmers remain in the Village.
- This strategy ensures continuous reinforcement of attacking power while maintaining a farming backbone and not over-exposing Farmers to Cave risk. It also uses resources efficiently to maximize the number of spawned Warriors early, which tends to reduce the Dragon’s counter-attack impact on the fields over the course of the game.

```py
from generated_adaptations.base_classes.dragon import DragonHuntAdaptation

class SmartAdaptation(DragonHuntAdaptation):
    def __init__(self, **kwargs):
        super().__init__(**kwargs)

    def assign_in_village(self, components, environment, group_ids, step: int):
        # Separate villagers by role
        farmers = [c for c in components if getattr(c, "role", None) == "Farmer"]
        warriors = [c for c in components if getattr(c, "role", None) == "Warrior"]

        num_farmers = len(farmers)
        farm_wheat = getattr(environment.farm, "wheat", 0)

        # Strategy:
        # 1) Spawn as many Warriors as possible using farmers and wheat
        # 2) Then spawn as many Farmers as possible with remaining resources
        # 3) Remaining farmers continue farming

        # Compute how many spawn-warrior groups we can form
        max_spawn_warriors = min(num_farmers // 2, farm_wheat // 12)

        # Wheat left after warrior spawns
        wheat_after_warrior_spawns = farm_wheat - max_spawn_warriors * 12

        # Compute how many spawn-farmer groups we can form with remaining resources
        max_spawn_farmers = min((num_farmers - max_spawn_warriors * 2) // 2, wheat_after_warrior_spawns // 10)

        # Feet for each group
        farmers_for_warrior_spawn = farmers[: 2 * max_spawn_warriors]
        idx_after_warrior = 2 * max_spawn_warriors

        farmers_for_farm_spawn = farmers[idx_after_warrior: idx_after_warrior + (2 * max_spawn_farmers)]
        idx_after_farm_spawn = idx_after_warrior + 2 * max_spawn_farmers

        remaining_farmers = farmers[idx_after_farm_spawn:]

        # Assign to groups
        for c in farmers_for_warrior_spawn:
            environment.assign_group(c, "spawn warrior")
        for c in farmers_for_farm_spawn:
            environment.assign_group(c, "spawn farmer")
        for c in remaining_farmers:
            environment.assign_group(c, "farm")

        # All Warriors go to the Cave (attack)
        for w in warriors:
            environment.assign_group(w, "cave")

    def assign_in_cave(self, components, environment, group_ids, step: int):
        # Warriors attack the Dragon; Farmers stay in Village
        warriors = [c for c in components if getattr(c, "role", None) == "Warrior"]
        farmers = [c for c in components if getattr(c, "role", None) == "Farmer"]

        for w in warriors:
            environment.assign_group(w, "attack")

        for f in farmers:
            environment.assign_group(f, "village")
```
